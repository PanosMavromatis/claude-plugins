# /agents-docs-build

Regenerate the agent-docs artifacts in this project. The bundled `scripts/build-agents-md.sh` walks `docs/agents/`, and for the root and every subdirectory that contains a `core.md` or `codex.md` it writes the matching `<path>/AGENTS.md` and/or `<path>/AGENTS.override.md`. Sources without a counterpart are skipped silently. The script is deterministic — same inputs produce byte-identical output.

`CLAUDE.md` is not regenerated by this command. It is an `@import` dispatcher; the `protect-agent-docs.py` hook keeps it intact.

## Run

Invoke the script once via Bash:

```
"${CLAUDE_PLUGIN_ROOT}"/scripts/build-agents-md.sh
```

Show its stdout verbatim — every `wrote …/AGENTS.md (… lines)` line is the signal the user needs to confirm the right artifacts were emitted.

If the script exits non-zero, surface its stderr exactly as written and stop. Do not retry, and do not attempt to write any `AGENTS.md` or `AGENTS.override.md` directly via `Write`/`Edit` — the `protect-agent-docs.py` hook would (correctly) block that.

## Do not

- Run `git add` or commit anything. The caller decides what to stage.
- Edit `docs/agents/` sources here. Those edits belong in `/agents-docs-update` or are made by the user directly.
