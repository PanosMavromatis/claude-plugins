# 01 — Move the export script into the plugin, with a suite

**Goal**: [x]
> **Done:** `scripts/export-session.py` is the tmp script with UTF-8 named on both ends and a usage error, byte-identical in output on a real log; `dev/export-session/` pins the three 2026-10-11 defects with eight cases and five mutants, each killed by the case aimed at it.
> **Q:** Should `dev/export-session/` carry a `mutants/` directory, like the five plan-script suites (A), or cases only (B)?
> **A:** A, one per rule.

- [x] `plugins/workflow-coding/scripts/export-session.py` starts from `tmp/export_session.py`, keeps its output form, and takes the log and the output path as arguments
  > **Note:** Ported with four changes: a header for the plugin, a usage error that exits 2 as the plugin's scripts do, UTF-8 named on both read and write, and closed file handles. On a snapshot of a real 15 MB log (125 operator messages, 281 replies, 4 compactions) its output is byte-identical to `tmp/export_session.py`'s. Under `LC_ALL=en_US.ISO8859-1` the original crashes encoding its own header's em dash, while the port writes each em dash once, with no mojibake: the case subgoal 3 needs, since a UTF-8 locale cannot tell them apart. Pyright flags `b.get` where a content block might be a string; that is unchanged from the original, since logs hold dicts.
- [x] A suite under `dev/export-session/`, in the shape of the other `dev/` suites, renders fixture logs with no model and checks the output
  > **Note:** The suite writes each fixture log in raw UTF-8, as Claude Code does (a real log held 6980 raw em dashes and no `\u` escapes), runs the script under a stated locale in a temporary directory, and checks the exit code, stderr, the summary counts and the output's bytes. `g01` renders every kind of record the script renders or skips, its expected output written by hand from the code, not captured; `g02` must match it under Latin-1. Eight cases pass in about 0.3 s. Unlike the plan suites it needs no `LOCATE_PLAN_WORK`, since it builds no repository.
- [x] Cases for the three defects fixed on 2026-10-11: an em dash is encoded once, the `/compact` instructions are captured, and the title comes from the output filename
  > **Note:** `e03` and `e04` pin the title, `e01` the em dash (run under `en_US.ISO8859-1`), and `e02` `/compact`'s arguments, across two lines. Against `tmp/export_session.py` the suite fails `e01` and `g02` (it crashes encoding the title's em dash under Latin-1) and `u01` and `u02` (it has no usage check), and passes the rest, so the three 2026-10-11 fixes were already in it. Five mutants, one per rule, are each killed by the case aimed at it; `m02`, reading in the locale's encoding, reproduces the 2026-10-11 defect byte for byte: `a \xc3\xa2\xc2\x80\xc2\x94 b`.
